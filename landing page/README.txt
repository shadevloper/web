SETUP
-----
1. Open the Google Sheet.
2. Extensions -> Apps Script.
3. Replace Code.gs with the included Code.gs.
4. Add HTML file named exactly "Index".
5. Paste Index.html into it.
6. Save.
7. Deploy -> New deployment -> Web app.
8. Execute as: Me.
9. Who has access: Anyone.
10. Authorize permissions.
11. Open the generated /exec URL.

IMPORTANT
---------
Index.html uses google.script.run, so it must be served through the Apps Script Web App.
Do not open Index.html directly from your computer.
